# 控制台 v4 · 功能重复检查与整理

日期：2026-10-17。检查对象：本地 HTML 交互原型，不代表真实后端完成验收。

## 已合并的重复

| 原问题 | 整理结果 |
| --- | --- |
| 侧栏有 11 个配置快捷项，定制中心又有同一组入口 | 侧栏仅保留定制中心；11 个模块在中心内进入，顶部提供模块切换与返回 |
| MCP 原列表显示已连接，新配置表却显示待实测 | 合为一张含能力、挂载成员、端点、传输、状态及编辑操作的列表；不冒充实际握手成功 |
| Skill 原卡片和新增编辑卡片重复展示同一批技能 | 合为 10 张可编辑卡片，原版能力说明放在卡片详情中 |
| Tool 原表和新增契约卡片重复展示同一批工具 | 合为 8 张契约卡片，保留全部 8 个权限选择器及调用方说明 |
| Tool 搜索供应商表和 Key 页重复管理凭据 | Tool 仅管理工具契约与权限，供应商凭据集中在 Key 页 |
| LLM 页和 Key 页都有供应商 Key 输入 | LLM 改为引用 Key 中心，提供跳转；独立引擎 Key 仍是明确的覆盖配置 |
| LiteLLM 的服务地址与供应商地址分别存储 | 保存后同步同一地址，两个视图不会各保留一份不一致的值 |

## 保留的合理分工

- 仪表盘 Token 概览与详细账本共用汇总代码，分别用于概览和逐次调用明细。
- 深度报告页用于研究需求、章节与数据合同；研判工作台用于证据和门禁过程；报告中心用于已产出报告及追问。
- 模板中心管理报告骨架；模板相关 Skill 定义选型和写作方法。
- LLM 管理供应商和通用角色路由；七槽用于引擎级绑定和覆盖；Key 管理凭据与服务地址。
- 采集守则定义策略，审批中心处理具体审批实例，运行日志记录执行事件。

## 验证结果

浏览器实测：11 个模块全部可从定制中心进入并返回，每页仅有一份内部导航；侧栏配置快捷项为 0；MCP 表为 1 张、服务为 6 项；Skill 为 10 张；Tool 为 8 张、权限选择器为 8 个；七槽仍为 7 个且修改值能在往返后回显。MCP 端点和 Skill 规则保存可回显。未知 usage 筛选下角色费用显示“未知”，不会显示为免费。当前主文档未发现重复 DOM ID。

另修正：服务地址先全部校验再统一保存，错误地址不会造成前几个字段已保存、后几个失败的部分写入。

配置仍只保存在页面内存，刷新清空；这里验证的是原型交互，不是后端配置落库、MCP 握手、真实模型调用或完整报告生产测试。
