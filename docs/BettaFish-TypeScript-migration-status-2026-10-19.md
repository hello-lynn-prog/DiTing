# BettaFish 能力 TypeScript 移植状态（2026-10-19）

## 本轮新增

- Insight、Media、Query 每轮必须先完成一次有结果的本地查询/搜索/抓取，再提交反思。每名成员至少两轮；非停止决策须列出下一批查询，停止后才能提交调查成果。
- ForumHost 与调查成员并行运行，按反思轮次等待、发布意见并让成员回流补证。ForumHost 最多三轮，意见仍作为待核实研究输入，不会自动成为事实。
- Media 新增图片/视频线索搜索，并从已归档网页抽取发布者声明的 OpenGraph/Twitter 图片和视频 URL；报告提供原网页溯源链接。
- 报告增加基于归档文档的 Jaccard 文本聚类、文档频率词云、SWOT 与 PEST 结构块。SWOT/PEST 条目须绑定本任务已核验结论；聚类和词云标明算法与样本范围。
- 微博/B站增加扫码登录入口：本机 Edge 持久化 profile 位于 `data/browser_data/`；原生 TS 采集器读取的 Cookie 单独加密保存在配置数据库，并继续使用已实现的冻结版本与采集审批机制。
- 当前值守规则已保存 12 个用户提供关键词，启用 15 分钟巡检、热度增长阈值 200%、自动开研究任务，并受每日任务数与预算限制。该设置已写入本机 `data/diting.sqlite3`，不会提交到 Git。

## 登录数据说明

`data/browser_data/{weibo,bilibili}` 是 Chromium 持久化用户目录，保存平台网页登录状态，只放本机且已被 `.gitignore` 的 `data/` 排除。网页端可继续手动录入 Cookie 作为备用方式。扫码登录后，TS 采集路径使用加密配置中的 Cookie 快照，不把账号状态交给模型；任务仍须显式选择 `saved_session` 并批准具体访问范围。
