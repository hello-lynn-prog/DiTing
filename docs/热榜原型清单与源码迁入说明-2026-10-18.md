# 热榜原型清单与源码迁入

v5 原型的 `HOTDATA` 有 27 个展示频道，包含财联社和金十在财经/A股分类的重复展示；实际对应 25 个采集源。原型是展示基线，里面已有的新闻、数值与日期没有导入为新采集记录。

先前后端的 27 个入口是另一份 DailyHotApi 常见来源清单，和原版不能对应。本次保留这些入口中的扩展内容，补进原版缺失的 13 个实现，最终是 **25 个原型采集源 + 15 个扩展源 = 40 个实际入口**。界面默认呈现原型 27 频道，扩展源单独筛选；同流重复展示不算独立事实。

## 源码与许可

- NewsNow：`newsnext/newsnow`，读取时固定 commit `0560c993b226cd2fd07d8a79875d50551f52c584`。本机旧目录只有构建依赖，本轮在忽略的临时目录取得完整上游源码，核对 GitHub、Solidot、ProductHunt、华尔街见闻、财联社与金十的取数逻辑。
- DailyHotApi：用户提供的本地源码 `D:/工作学习/9github项目/Agent_program/产品调研/github项目/DailyHotApi`，核对腾讯、网易、新浪新闻/财经、Hacker News 和虎扑路由；本地快照无明确固定 Git commit，不编造版本号。
- 两者的 HTTP 路由、缓存和 UI 未作为独立服务运行；平台取数、响应解析迁入 `packages/collectors/hotlists.ts`，统一落原始快照、条目、状态与审计。
- 改写来源说明与完整 MIT 许可保存在 `assets/licenses/NewsNow-MIT.txt`、`assets/licenses/DailyHotApi-MIT.txt`。BettaFish 提示词、模板或引擎没有因此变成 MIT 代码。

## 逐平台结果

详见机器可读的 `hotlist-live-verification-2026-10-18.json`。最新各源状态汇总为 34 成功、6 失败。成功表示取得并解析了榜单/列表，不保证来源报道属实、榜单有数值热度、数据仍是最新或覆盖完整公众讨论。

失败为微博 403、抖音返回风控拒绝、雪球验证页面、Hacker News 超时，以及扩展源 V2EX 超时和地震台证书过期。未关闭 TLS 校验、未处理验证码或把旧缓存标成新成功。

没有热度数值的原文/快讯保持空值；内容榜、Star、播放量、回复数、公共预警都分别标注口径。内部读取 Solidot/ProductHunt 官方 feed 是采集手段，没有恢复已经删除的用户 RSS 订阅功能。
