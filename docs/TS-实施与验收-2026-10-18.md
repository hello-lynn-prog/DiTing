## 已落地

- 将旧 Python 基线保留为迁移输入，新增 TypeScript/Fastify 主服务与本机 SQLite 数据层；生产启动前对旧库自动做一致性备份。旧会话、任务、消息、证据与结论摘要迁移后字段与哈希回归通过。
- 使用本机锁定 dsh 源码 `D:/Study/deepseek_harness/deepseek-harness`（commit `9fcc9f4d6ea6e02ab92ed12bfb2ca627b3363035`，package build `0.2.0-rc.2`）的官方 SDK；创建 DiTing profile 与 TypeScript domain plugin。
- 原生 dsh 子 Agent 角色配置包含 Insight、Media、Query、ForumHost、Planner、Verifier、Advocate、Report。预算预留、工具权限、任务租约、模型用量、证据和门禁均由 DiTing 业务代码记录。
- 构造的完整合成验收创建了 8 个真实 dsh 子会话，完成三位调查成员、主持、三道审查、Report 分阶段写作与报告候选。成稿结构和数字校验通过，HTML/MD/PDF 本机导出成功。执行数据位于隔离临时目录，未伪装成现实研究报告。
- 模型端点增加 Anthropic Messages 原生协议。GLM-5.3-Flash 对话路由已加密保存在本机配置中。首次真实 endpoint 探测返回 200；DiTing 持久 API 对话端到端成功，返回模型文本；两次 DiTing 对话调用与两次接口连通性探测都已记入账本，合计输入 159、输出 433 Token；其中一次短探测无可展示文本，标为 `incomplete_response`。服务重启后模型调用仍成功，确认加密凭据可解密复用。因未填供应商计价表，4 次费用均为未知（NULL），不是零。
- 四个热榜原生直连解析器；最近一次真实平台采集验证知乎20条、百度50条、哔哩哔哩100条成功，微博 HTTP 403；测试数据只保存在临时 QA 数据库。
- 20 项 TypeScript 单元/API/DOM/迁移/网络边界自动化用例通过（含 Anthropic 与 Firecrawl 协议路径、报告归档持久化）；PDF 合成导出曾由本机 Chromium 生成并进行版式检查。

## 当前实际模型设置

- `chat` 槽配置为 `anthropic-messages`、GLM-5.3-Flash、用户提供的智谱 endpoint；API 密钥仅存于 `data/master.key` 加密引用，不入源码或普通配置响应。
- `planner/insight/media/query/forum/report` 六个研究槽已复用对话槽的密钥引用、Anthropic 协议和 GLM 模型，无需再次暴露密钥。仍需在各研究槽填写准确单价；当前健康检查只缺费率，runtime 开关保持关闭，因此不会误启动收费研究。
- 本轮没有导入任何参考仓库 `.env` 或凭据。

## 尚未声称完成的范围

- NewsNow 与 DailyHotApi 当前只提供功能参考及采集 API 设计参考；DiTing 实现四个自有 TS 来源解析器，不含完整原项目源码，也未覆盖原先提到的 27/52个平台数量。
- MediaCrawler 登录态评论抓取、平台级关键词深爬、多模态分析尚未实现；公开 URL 的五页审批接口不等同它们。
- MCP 与 Skill 配置页是登记/配置界面；第三方程序尚未自动加载。
- 真实主题研究、外部搜索 keys、Firecrawl keys、通知 credentials、渠道签名和真实投递仍需逐项设置和验收。
- 当前产品是单用户本机版本，不是公网服务，不保证第三方服务的持续可用性。
