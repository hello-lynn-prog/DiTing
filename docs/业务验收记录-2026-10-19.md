## 当前需要用户提供的业务条件

- 微博/B站关键词深采：请在本机浏览器分别登录微博和 B 站，并在 DiTing「定制中心 → Key 与服务配置」附近的平台登录态配置中保存会话；不要把 Cookie 粘贴到对话。登录成功后提供一个可公开验证、可用于采样的研究关键词。
- 值守规则：提供要监测的主题/关键词、升温阈值和自动开任务策略；目前规则为 0，自动采集计划保持关闭，不擅自创建业务规则或开启后台持续联网。
- 成本基线：授权总额上限，并给 2–3 个代表主题/时间窗；每个真实研判会调用外部模型并产生费用。
- 云端 CI：本地仓库没有 Git remote。提供目标 GitHub remote URL 后，再配置推送和验证远端 workflow；本地 typecheck 与测试已执行。
