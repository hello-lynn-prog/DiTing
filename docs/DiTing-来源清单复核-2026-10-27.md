# DiTing 来源清单复核（2026-10-27）

## 处理原则

用户要求优先修复失败源；仍被平台拒绝的来源退出默认采集。旧快照、失败流水和解析器保留，信源页显示暂停原因并允许手动复测。暂停不代表平台永久不可用，也不把验证页或聚合站内容冒充原平台热榜。

参考 [糖果梦 RSS 与分类目录](https://tgmeng.com/rss) 发现候选后，本轮仅接入从**原站**取得并通过 DiTing 原生 TypeScript 解析器验证的订阅源；没有调用糖果梦聚合接口。新增资讯流提供新闻线索和原始链接，不提供平台热度，也不与热搜指数比较。

原站 RSS 实测：`https://readhub.cn/rss` 返回 20 条科技资讯，`https://www.chinanews.com.cn/rss/scroll-news.xml` 返回 30 条滚动新闻；两者的发布时间、标题、原始链接和摘要按原样归档，热度为 `null`。备选 Sixth Tone 在普通 `fetch` 中曾得到 RSS，但 DiTing 实际抓取器经重定向拿到非 RSS 响应，因此未接入。IT之家和极客公园 RSS 可访问，但项目已有同站来源，为免把同一站重复计算成两个独立平台，本轮未新增。

目录现在是 **54 个登记入口，48 个参加无指定来源的默认采集，6 个暂停**；原 v5 的 27 个展示频道不删除。10 月 27 日后台恢复后，默认采集一轮结果是 **47 成功、1 失败**，唯一失败为 `dailyhot:csdn` 偶发 HTTP 521。随后同一原站接口单独重测取得 30 条；代码对该 521 增加一次且仅一次同地址重试，403 等平台拒绝不重试。该单独成功不改写首次失败，也不能宣称一次 48/48 全通过；下一轮完整采集仍须观察。

`npm run typecheck`、`npm run build`、`npm test` 及实际端点探测是本轮验收；测试通过不代替下一次定时采集或 24 小时稳定性验收。历史失败原因与原始响应继续留在正式数据库中。
